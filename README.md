# PageEdit — ビジュアルWebエディタ

ブラウザだけで動く、単一 HTML のビジュアルページエディタです。ビルドやインストールは不要で、`index.html` をブラウザで開くだけで使えます。

## 主な機能

- キャンバス（760×480）への要素追加：テキスト／四角形／円／ボタン／画像プレースホルダ／カード
- ドラッグで移動、8方向ハンドルでリサイズ、ダブルクリックでテキストを直接編集
- プロパティ編集：位置・サイズ・角丸・透明度・文字（内容・色・揃え・フォント・太字・斜体）・塗り・線
- アニメーション：16種類のプリセット、時間・遅延・繰り返し・イージング・方向・トリガー（読込時／クリック時／ホバー時）
- タイムライン表示と全アニメーションのプレビュー
- レイヤー一覧、前面／背面、複製、削除、全削除
- 元に戻す／やり直す
- アニメーション付きの単体 HTML として書き出し（`page-export.html`）

## キーボードショートカット

| キー | 動作 |
|---|---|
| Ctrl+Z | 元に戻す |
| Ctrl+Y / Ctrl+Shift+Z | やり直す |
| Ctrl+D | 複製 |
| Delete / Backspace | 選択中の要素を削除 |
| 矢印キー | 1px 移動（Shift で 10px） |
