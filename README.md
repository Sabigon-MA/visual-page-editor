# visual-page-editor（PageEdit）

プログラマーとノンプログラマーの双方が使える Web デザインアプリケーションです。キャンバスでのビジュアル編集とコードエディタがリアルタイムに双方向同期し、React / Vue + TypeScript のソースコードやスタンドアロン HTML として書き出せます。

## セットアップ

```sh
npm install
npm run dev        # 開発サーバー（http://localhost:5173）
npm run build      # 型チェック + 本番ビルド（dist/）
npm test           # テスト（Vitest）
```

技術スタック：Vite / React 19 / TypeScript / Zustand / Monaco Editor / CSS Modules / @babel/parser（コード解析）/ fflate（zip）/ FileSaver.js

## 使い方

上部ツールバーで2つのモードを切り替えます。

| 切り替え | 内容 |
|---|---|
| ノーコード ／ プログラマー | プログラマーにすると、キャンバスの横にコードエディタが開く |
| 編集 ／ プレビュー | プレビューでは書き出し後と同じ動き（フォーム操作・アニメーションのトリガー）を確認できる |

### ビジュアル編集

- 要素の追加：左サイドバーのクリック／キャンバスへのドラッグ、上部「＋ 要素を追加」、キャンバスの右クリック
- ドラッグで移動、8方向ハンドルでリサイズ、ダブルクリックでテキストを直接編集
- 右パネル：位置・サイズ、塗り・ボーダー（色・幅・線種）・角丸・透明度・影、テキスト・文字色・揃え、アニメーション
- レイヤーパネル：ドラッグで並び替え、表示／非表示、ロック
- タイムライン：アニメーションの遅延・長さを表示。バーをクリックすると、その要素のアニメーション設定を開く

要素タイプ：テキスト、見出し、四角形、円、区切り線、ボタン、入力欄、テキストエリア、チェックボックス、ラジオボタン、セレクトボックス、スライダー、画像プレースホルダー、カード

### コードエディタ（プログラマーモード）

- 表示形式は React (TSX) と Vue (SFC) から選べます。
- キャンバスを操作すると、コードがすぐに書き換わります。
- コードを編集すると、入力が止まってから 0.3 秒後に解析し、キャンバスへ反映します。
- 構文エラーや不正な値は、エディタ上の波線と下部の一覧で表示します。エラーがある間はキャンバスに反映しません。
- キャンバスで選択した要素の行を強調表示します。

各要素は `<Box>` で表します。スタイルは、要素タイプごとの既定値と違うものだけを書きます。

```tsx
<Box id="e2" type="text" x={80} y={106} w={360} h={36} color="#6b6b68" fontSize="15px"
  anim={{ type: 'fadeIn', duration: 0.8, delay: 0.3, iter: '1', easing: 'ease', direction: 'normal', trigger: 'onLoad' }}>
  説明文をここに入力します
</Box>
```

- 値には、文字列・数値・真偽値・オブジェクトのリテラルだけを使えます。変数や式は使えません。
- 中身のテキストが要素の `text` になります。ラジオボタンとセレクトボックスでは、カンマ区切りの選択肢になります。
- Vue では、数値とオブジェクトを `:x="80"` のようにバインドし、プロパティ名はケバブケース（`font-size`）で書きます。

### キーボードショートカット

| キー | 動作 |
|---|---|
| Ctrl/⌘ + Z | 元に戻す |
| Ctrl/⌘ + Y / Ctrl/⌘ + Shift + Z | やり直す |
| Ctrl/⌘ + D | 複製 |
| Ctrl/⌘ + B / I | 太字 / 斜体 |
| Delete / Backspace | 削除 |
| ↑↓←→（Shift で 10px） | 1px 移動 |
| Escape | 選択解除 |

コードエディタや入力欄で入力している間は、これらのショートカットは働きません。代わりにエディタ自身の操作になります。

## 書き出し

| ボタン | 出力 |
|---|---|
| HTMLを書き出す | `craft-export.html`。外部 JS 不要のスタンドアロン HTML |
| ソースを書き出す (.zip) | `craft-export-react.zip` / `craft-export-vue.zip`。Vite + TS のプロジェクト一式（`npm install && npm run dev` で動く） |

- HTML 書き出しは、使っているアニメーションの `@keyframes` だけを出力します。各要素は `el-1`〜`el-N` の `position:absolute` で配置し、Google Fonts を読み込みます。非表示の要素は出力しません。
- 書き出したソースコードには、`src/runtime/`（`<Box>` コンポーネント・既定値・スタイル・キーフレーム）がそのまま `src/vpe/` として入ります。エディタのキャンバスも同じ `<Box>` で描画しているので、書き出し後と見た目が一致します。

## ディレクトリ構成

```
src/
├── components/
│   ├── Canvas/        # キャンバス本体・要素（選択・移動・リサイズ・インライン編集）
│   ├── CodeEditor/    # Monaco Editor ラッパー（双方向同期・エラー表示）
│   ├── Panels/        # 左サイドバー・右パネル（プロパティ・アニメーション・レイヤー）
│   ├── Timeline/      # タイムライン・再生・書き出しボタン・ステータスバー
│   ├── Toolbar/       # 上部ツールバー
│   ├── ContextMenu/   # 右クリックメニュー
│   └── common/        # 入力部品
├── store/
│   ├── elements.ts    # 要素配列・選択状態（Zustand）
│   └── history.ts     # Undo/Redo（スナップショット方式）
├── codegen/           # 要素配列 → React TSX / Vue SFC / HTML / zip
├── parser/fromCode.ts # コード → 要素配列（AST 解析）
├── runtime/           # 書き出し先にも同梱する <Box> と既定値・スタイル・アニメーション
├── model/             # 要素タイプ・アニメーションの一覧
├── types/element.ts   # 要素の型定義
└── App.tsx
```
