# visual-page-editor（PageEdit）

プログラマーとノンプログラマーの双方が使える Web デザインアプリケーションです。複数のページ（画面）をキャンバスでビジュアルに作成し、ページ同士のつながり（画面遷移）を設定できます。キャンバスとコードエディタはリアルタイムに双方向同期し、React / Vue + TypeScript のソースコードやスタンドアロン HTML として書き出せます。

## セットアップ

```sh
npm install
npm run dev        # 開発サーバー（http://localhost:5173）
npm run build      # 型チェック + 本番ビルド（dist/）
npm test           # テスト（Vitest）
```

技術スタック：Vite / React 19 / TypeScript / Zustand / Monaco Editor / CSS Modules / @babel/parser（コード解析）/ fflate（zip）/ FileSaver.js

### デスクトップアプリ（Tauri）

同じコードを Tauri で Windows のデスクトップアプリとして動かせます。Rust（rustup の stable-msvc）、Visual Studio の C++ ビルドツール、WebView2 が必要です。

```sh
npm run app:dev    # デスクトップ版を開発モードで起動
npm run app:build  # インストーラーを作成（src-tauri/target/release/bundle/nsis/ に setup.exe）
```

デスクトップ版では、プロジェクトの保存・読み込みと書き出しに OS のファイルダイアログを使います（ブラウザ版はダウンロード）。保存の詳細は「[保存](#保存)」を参照してください。

## 使い方

### スタート画面

起動するとスタート画面（パワーポイントのホーム画面と同じ形）を表示します。

- **新しいプロジェクトを作成** → 空白のページで編集画面へ
- **続きから編集**：前回作業していたプロジェクトがあれば、サムネイル付きで表示します（自動保存から戻します）
- **最近使ったファイル**（デスクトップ版）・**開く**：プロジェクトファイルを開いて編集画面へ
- 編集画面からは「ファイル ▸ ホーム」でスタート画面に戻れます（作業中のプロジェクトは「続きから編集」で戻れます）。「ファイル ▸ 新規」は、保存していない変更を確かめてから新しいプロジェクトを作ります。
- `.vpe` ファイルをダブルクリックして起動したときは、スタート画面を経ずにそのファイルを開きます。

### 作ってあるサイトの見た目を調整する（デスクトップ版）

すでにある Vite + React のプロジェクトを、動くままの状態で開いて、色・文字・余白などの見た目だけを変えます。変更は CSS にだけ書くので、ボタンの処理・フォームの送信・データの取得などの動きは変わりません。

1. スタート画面の「プロジェクトのフォルダを開く…」で、`package.json` があるフォルダを選びます（先に `npm install` を済ませておきます。Node.js が必要です）。
2. PageEdit がそのプロジェクトの Vite を、プロジェクトの設定（`vite.config`）のまま起動して表示します。API のプロキシなどもそのまま使えます（バックエンドは別に起動しておきます）。
3. 「要素を選ぶ」をオンにしてページの要素をクリックし、右のパネルで見た目を変えます。オフにすると、ページを普通に操作できます（ほかの画面に移動してから選ぶ、など）。
   - 「変える範囲」で、この要素だけか、同じクラスの要素すべてかを選べます。セレクターを直接書き換えることもできます。
   - 左の「色」では、テーマの色（`:root` の CSS 変数）を変えたり、使われている色をまとめてほかの色に置き換えたりできます。「変更の一覧」で、変更を確かめたり消したりできます。
4. 「保存」（Ctrl + S）で、エントリーファイル（`src/main.tsx` など）と同じフォルダの `pageedit-overrides.css` に書きます。はじめて保存するときだけ、エントリーファイルの最後に `import './pageedit-overrides.css';` を1行足します（確認が出ます）。

- 書き込むのは `pageedit-overrides.css` と、上の1行だけです。ほかのファイルは変えません。`pageedit-overrides.css` と import の行を消すと元の見た目に戻ります。
- どの値も `!important` で書くので、元の CSS や JSX の `style` より優先されます。
- CSS Modules のクラス（`_title_1x2y3_4` など）は、CSS を変えると後ろのハッシュが変わるため、名前の部分（`title`）で選びます。
- いまはすべての画面の幅に同じ値が効きます（幅ごとの値や、ホバー時の見た目は `pageedit-overrides.css` に手で書き足せば残ります）。

### ページの幅と長さ（レスポンシブ）

画面サイズを選ぶ必要はありません。ページは PC 用に幅 1440px で作り、スマホ用のレイアウト（幅 390px）は自動で作ります。書き出したページは、見る人の画面の幅に合わせて伸び縮みします。

| 画面の幅 | 表示 |
|---|---|
| 1440px より広い | 中身は幅 1440px で中央に置き、幅いっぱいの帯（セクションの背景など）は画面の端まで伸ばす |
| 768〜1440px（ノート PC・タブレット） | 中身を比率を保ったまま縮めて、画面の幅に収める |
| 767px 以下（スマホ） | スマホ用のレイアウトで表示する |

- 「幅いっぱいの帯」は、ページの左端から右端まである要素です（回転していないもの）。帯はいつも中身の後ろに重なります。
- Web ページは縦にスクロールして見るものなので、ページの長さは自由です。キャンバスの下端の「ページの長さ」をドラッグするか、ページの設定の「長さ」で変えます（ダブルクリック・「戻す」で元の長さに戻します）。要素が下にはみ出すと、その下端まで伸びます。全ページ共通のフッターは、ページの下端に付きます。
- キャンバスのオレンジの点線は「最初に見える範囲の目安」（高さ 900px）です。この線より下はスクロールして見る部分です。
- キャンバスは、はじめはページの幅に合わせて表示し（「幅に合わせる」、Ctrl + 0）、縦にスクロールして編集します。
- 以前のバージョンで作った、ほかの画面サイズのプロジェクトは、その幅のまま開けます。

### ページと画面遷移

- 左サイドバーにページのサムネイルが並びます（パワーポイントのスライド一覧と同じ）。ページの追加（＋、Ctrl + M）・切り替え・名前の変更（名前のダブルクリック）・並べ替え（ドラッグ）・複製・削除（右クリック）ができます。先頭のページが最初に表示されるページです。
- 要素を選んで、右パネルの「リンク（クリックで移動）」で移動先を選ぶと、その要素をクリックしたときに移動します。移動先は「このサイトのページ」「Web サイト（URL。新しいタブで開くこともできます）」「メール」「電話」から選べます。「＋ 新しいページを作ってリンク」で、移動先のページを作りながら設定することもできます。
- リンクにした要素は、書き出したページで普通の `<a href>` になります（検索エンジンがたどれます）。
- キャンバス上部の「画面遷移図」タブ（または「表示 ▸ 画面遷移図」）で、全ページをカードで並べ、リンクを矢印（クリックする要素 → 移動先のページ）で表示します。カードはドラッグで動かせ、「自動で並べる」で最初のページから順に左から右へ並べ直します。カードのダブルクリックでそのページを編集、矢印のラベルのクリックでその要素を選択します。
- プレビュー（F5、Esc で編集に戻る）では、リンクを設定した要素をクリックするとページが切り替わります（「← 戻る」で前のページへ）。

### 画面の構成

パワーポイントと同じ構成です。

- 上部のリボン：「ファイル｜ホーム｜挿入｜デザイン｜配置｜表示」のタブ。左端に上書き保存・元に戻す・やり直す（保存していない変更があると保存ボタンに点が付きます）、右端に編集／プレビュー・ノーコード／プログラマーの切り替え
  - **ファイル**：新規・開く・上書き保存・名前を付けて保存、最近使ったファイル（デスクトップ版）、サイトの設定、書き出し（Web サイト・HTML・React・Vue）
  - **ホーム**：貼り付け・切り取り・コピー・書式のコピー、新しいページ、フォント（種類・サイズ・太字・斜体・文字色・揃え）、塗り・枠線、複製・削除・すべて選択。書式は選択中の要素すべてに設定します
  - **挿入**：新しいページ、セクション（ひな形）、画像、図形、テキスト・見出し・カード、表、フォーム部品。クリックで見えている範囲の中央に追加（重なるときは少しずらす）、キャンバスへドラッグして好きな位置に追加
  - **デザイン**：テーマの色（クリックで変更）、配色の候補、サイトの設定
  - **配置**：整列・等間隔、重なり順、グループ化・解除、回転（右へ 90°・左へ 90°・戻す）、ロック・非表示
  - **表示**：キャンバス／画面遷移図、ズーム、アニメーションの再生、プレビュー、コードエディタ
- 左：ページのサムネイル一覧　右：プロパティ・アニメーション・レイヤー（要素を選んでいないときは、ページの設定）　下：ステータスバー（右端にズームスライダー）
- キャンバスの上：キャンバス／画面遷移図のタブと、PC／スマホの表示の切り替え
- アニメーションのタイムラインは、アニメーションを設定したページでだけ下に表示します。

### ビジュアル編集

- ドラッグで移動、8方向ハンドルでリサイズ、上の丸いハンドルで回転
- ダブルクリックでテキストを直接編集。図形の中にも文字を書けます。テキスト・見出し・図形・カードは Enter で改行し、Esc（または Ctrl + Enter）で編集を終えます
- **Shift + ドラッグ**：水平・垂直にだけ移動／角のハンドルで縦横比を保ってリサイズ／回転は 15° 刻み
- **Ctrl + ドラッグ**：コピーしながら移動
- 移動・リサイズ中は、他の要素や画面の端・中央に吸着し、ガイド線を表示します。端・中央に吸着しないときは、同じ行・列の要素と等間隔になる位置（両隣の真ん中、他の要素どうしと同じ間隔）に吸着し、間隔の印を表示します（Alt を押している間は吸着しません）
- 複数選択：Shift / Ctrl + クリック、空いている所からドラッグで囲む、Ctrl + A。まとめて移動・削除・複製・コピーでき、選択範囲の枠のハンドルでまとめて拡大・縮小できます。整列（左・左右中央・右・上・上下中央・下）と等間隔の配置ができ、1つだけ選んで整列すると画面に対して揃えます。
- **グループ**（Ctrl + G、解除は Ctrl + Shift + G）：クリックするとグループ全体を選び、もう一度クリックするとグループの中のその要素だけを選びます。グループ化すると重なり順で一番前面の要素の位置に集まります。複製・貼り付けしたグループは別のグループになります。
- **書式のコピー**（ホーム ▸ 書式のコピー、Ctrl + Shift + C / Ctrl + Shift + V）：塗り・枠線・文字の書式をほかの要素に貼り付けます。ボタンをダブルクリックすると、Esc を押すまで続けて貼り付けられます。図形の形は変わりません（円は円のまま）。
- コピー・貼り付けはページをまたいで使えます。
- 右パネル：位置・サイズ・回転、画像（代替テキスト）、フォーム（項目名・種類・必須）、リンク、マウスを乗せたとき、全ページ共通、塗り・ボーダー（色・幅・線種）・角丸・透明度・影、テキスト・文字色・揃え・フォント・太さ・サイズ・行間・字間・HTML タグ（見出し1〜6・段落）、アニメーション
- **リンク**：クリックしたときの移動先を「このサイトのページ」「このページ内の位置」（見出しなどの位置・ページの先頭へなめらかにスクロール）「Web サイト（URL）」「メール」「電話」から選びます。ボタンは「フォームを送信」にもできます。
- **マウスを乗せたとき**：塗り・文字色・影・拡大・上への移動・下線を変えられます（「浮き上がる」「少し拡大」「下線」はワンクリック）。この欄にマウスを乗せている間は、キャンバスでもその見た目で表示します。
- 色は、テーマの色・標準の色・なし（透明）・その他の色（自由に選ぶ）から選びます。
- レイヤーパネル：ドラッグで並び替え、表示／非表示、ロック。グループの要素にはグループ名が付きます（クリックでその要素だけを選択）
- Space + ドラッグで表示位置を動かせます。

要素タイプ：テキスト、見出し、メニュー、お知らせ一覧、四角形、円、三角形、ひし形、矢印、星、吹き出し、区切り線、矢印線、ボタン、入力欄、テキストエリア、チェックボックス、ラジオボタン、セレクトボックス、スライダー、画像、カード、表

- **図形**（三角形・ひし形・矢印・星・吹き出し・矢印線）は SVG で描き、塗りは「塗り」、線は「ボーダー」の色・太さ・線種で描きます。矢印線は左から右向きで、回転させて向きを変えます。
- **表**は、1行が表の1行、カンマでセルを区切ったテキストです（先頭の行は見出し）。右パネルの「セル」で編集し、「＋ 行」「＋ 列」で増やせます。ダブルクリックでも編集でき、Enter で改行、Ctrl + Enter で確定します。罫線は「罫線」（ボーダー）の色・太さです。
- **フォント**は日本語（Noto Sans JP・Noto Serif JP・Zen 角ゴシック New・Zen 丸ゴシック・M PLUS Rounded 1c・しっぽり明朝・BIZ UDPゴシック・解星デコール）と欧文（Inter・Montserrat・Poppins・Lora など）の Google Fonts から選べます。書き出したページは、使っているフォントだけを読み込みます。
- **見出しのタグ**：見出しは `<h2>`、テキストは `<p>` で書き出します。右パネルの「HTML」で見出し1〜6・段落に変えられます（見出し1はページに1つにすると、検索エンジンにページの題名が伝わりやすくなります）。
- **メニュー**（挿入 ▸ メニュー）は、サイトのナビゲーションです。PC では項目を横に並べ、スマホでは ☰ ボタンになり、押すと画面いっぱいにメニューを開きます（幅を 64px 以下にすると PC でも ☰ ボタン）。項目とリンク先（ページ・ページ内の位置・URL）は右パネルの「メニューの項目」で編集します。表示中のページの項目には下線が付きます。「マウスを乗せたとき（項目ごと）」で、項目の文字色・下線を変えられます。
- **お知らせ一覧**（挿入 ▸ お知らせ）は、日付とタイトルを1件ずつ並べた一覧です。お知らせの追加（先頭に今日の日付で入ります）・並べ替え・削除、リンク先（ページ・ページ内の位置・URL）は右パネルの「お知らせ」で編集します。スマホの画面では日付の下にタイトルを表示します。
- **フォーム**：入力欄・テキストエリアなどに「項目名」を付け、ボタンのリンクを「フォームを送信」にして、ページの設定の「フォーム ▸ 送信先」に Formspree などのフォーム送信サービスの URL（https）を入れると、送信ボタンで入力内容をその URL へ送ります。入力欄の種類（メールアドレス・電話番号・数字）と必須も設定できます。
- **画像**は「挿入 ▸ 画像」でファイルから選ぶほか、画像ファイルをキャンバスにドロップ、クリップボードの画像を Ctrl + V で挿入できます（PNG・JPEG・GIF・WebP・SVG）。長い辺が 2000px を超える画像は縮小し、WebP にすると小さくなる画像は WebP にして、プロジェクトに埋め込みます（ファビコン・SNS 用の画像は元の形式のまま）。角をドラッグすると縦横比を保ったまま拡大・縮小します（Shift で自由に変形）。右パネルで画像の変更・元の縦横比に戻すができます。「画像の枠」は画像のない枠（プレースホルダー）で、後から画像を選べます。

### セクション（ひな形）

「挿入 ▸ セクション」から、Web サイトでよく使うまとまりを入れます。ヘッダー・ヒーロー（大きな見出しとボタン）・特徴（3列）・料金プラン・お知らせ・行動の呼びかけ・よくある質問・お問い合わせ（入力欄と送信ボタン）・フッター。

- ページの一番下に足します（ヘッダーはページの先頭に入れ、ほかの要素を下にずらします）。1つのセクションは1つのグループです。
- ヘッダーのメニューはスマホで ☰ ボタンになり、お問い合わせの入力欄には項目名（name・email・message）と送信ボタンが入っています。ボタン・メニューにはマウスを乗せたときの動きが付いています。

### 全ページ共通のヘッダー・フッター

- 要素（グループ）を選んで、右パネルの「全ページ共通」の「ヘッダーにする」「フッターにする」（または右クリック）で、すべてのページに表示するパーツにします。どのページで編集しても、すべてのページに反映されます。
- ヘッダーはページの上端に、フッターは各ページの中身の下（中身がページの長さより短ければページの下端）に付きます。スマホの表示でも同じです。
- キャンバスでは紫の点線の枠で範囲を示します。「このページだけの要素に戻す」で、編集中のページの要素に戻せます（ほかのページからは消えます）。
- ヘッダーを選んで「スクロールしても画面の上に固定する」をオンにすると、ページをスクロールしてもヘッダーが画面の上端に残ります（プレビューで確かめられます）。ページ内リンクでスクロールしたときは、移動先がヘッダーに隠れない位置で止まります。
- 書き出したページには、各ページにヘッダー・フッターの要素が入ります。
- 画面の幅に合わせて組み立てます（PC では横に並べ、スマホの画面では縦に並べます）。
- 色はテーマの色を使うので、「デザイン」タブで配色を変えるとセクションの色も変わります。

### デザイン（テーマの色）

- 「デザイン」タブに、サイト全体で使う色（テーマの色：メイン・アクセント・文字・背景・背景（薄））が並びます。色をクリックして変えると、その色を使っている要素がすべて変わります。
- 「配色」の候補（スタンダード・ビジネス・ナチュラル・カフェ・ポップ・エレガント・テック・メディカル）をクリックすると、テーマの色にまとめて当てはめます。
- 要素の色を選ぶときに「テーマの色」から選ぶと、その要素はテーマの色を使います（色の四角の右下に印が付きます）。新しく追加したボタン・テキスト・見出しは、はじめからテーマの色を使います。
- テーマの色の追加・名前の変更・削除は「サイトの設定」でできます。削除した色を使っていた要素は、その時点の色のままになります。
- 書き出したページでは、テーマの色は CSS 変数（`--c1` など）になります。

### スマホ表示（レスポンシブ）

PC 用のページ（幅 768px 以上）は、スマホ用のレイアウトを持ちます。

- キャンバスの右上の「PC／スマホ」で切り替えます。スマホの表示（幅 390px）では、要素の位置・大きさ・文字の大きさを、PC とは別に調整できます。テキスト・色などの内容は PC と共通です。
- スマホ用のレイアウトは、PC の配置から自動で作ります。カードや帯（幅いっぱいの背景）の中身はその中に収めたまま、上から1列に並べ、短いメニューなどは横に並べます。大きな文字は小さくし、テキストの高さは折り返しに合わせます。
- スマホの表示で削除すると、スマホでだけ非表示になります（PC には残ります。レイヤーパネルで表示に戻せます）。
- スマホの表示で調整したあとに PC で追加した要素は、スマホでは一番下に自動で並べます。「自動で並べ直す」で、そのページのスマホ用レイアウトを PC の配置から作り直します。
- 書き出したページは、画面の幅が 767px 以下のときスマホ用のレイアウトで表示します。スマホでは表示の幅を 390px にするので、どの機種でも画面の幅ちょうどに収まります（タブレットでは PC のレイアウトを画面の幅に合わせて表示します）。

### ページの設定とサイトの設定

- 要素を選んでいないとき、右パネルに編集中のページの設定を表示します：名前、ファイル名（静的サイトとして書き出したときの URL。`about` → `about.html`）、背景色、検索結果・SNS での表示（タイトル・説明文。検索結果での見え方の例も表示します）。
- ページにフォームの入力欄があれば、ページの設定に「フォーム ▸ 送信先」を表示します。
- 「ページが見つからないときに表示する」をオンにしたページ（最初のページ以外）は「404 ページ」になります。Web サイト（公開用）では `404.html` として書き出し（多くのホスティングサービスが、存在しない URL でこのページを表示します）、検索結果に出さない設定と、どの URL でも画像やリンクが正しく読み込まれる設定（`<base>`）を入れます。HTML（1ファイル）・React / Vue では、ないページ（`#/xxx`）を開いたときに表示します。ページの一覧には「404」と表示します。
- 「ファイル ▸ サイトの設定」（または「デザイン ▸ サイトの設定」）：サイト名（各ページのタイトルの後ろに「 | サイト名」と付けます）、言語、ファビコン、公開する URL、SNS で共有したときの画像、Google アナリティクスの測定 ID、「ページの先頭へ」ボタン（スクロールすると右下に出ます）、ページの背景色（全ページ共通）、テーマの色。
- 公開する URL（`https://example.com`）を設定すると、Web サイト（公開用）の書き出しに `sitemap.xml` と各ページの正式な URL（`canonical`・`og:url`）を入れます。SNS で共有したときの画像（横 1200 × 縦 630 px がおすすめ）は `og:image` になります（公開する URL が必要です）。
- Google アナリティクスの測定 ID（`G-XXXXXXXXXX`）を設定すると、書き出したページ（Web サイト・HTML・React / Vue の `index.html`）にアクセス解析のタグを入れます。エディタのプレビューでは送りません。

### 保存

- 編集内容は自動保存され、次に起動したときに続きから編集できます（画像は IndexedDB に保存します）。
- 「上書き保存」（Ctrl + S）・「名前を付けて保存」（Ctrl + Shift + S）でプロジェクトファイル（`.vpe`。中身は JSON）に保存し、「開く」（Ctrl + O）で読み込めます。以前の `.vpe.json` / `.json` も開けます。読み込むときは内容を検証し、不正なファイルは理由を表示して開きません。
- 埋め込んだ画像もプロジェクトファイルに入ります（使っていない画像は保存しません）。
- デスクトップ版：
  - 開いた・保存したファイルに上書き保存します。まだ保存していなければ保存先を選びます。
  - ウィンドウのタイトルにファイル名を出し、保存していない変更があれば先頭に ● を付けます。
  - 保存していない変更があるときに、新規作成・別のファイルを開く・ウィンドウを閉じると、保存するか尋ねます（保存／保存しない／キャンセル）。
  - 「ファイル」に最近使ったファイル（10件）を表示します。
  - `.vpe` ファイルをダブルクリックするとアプリで開きます。アプリがすでに起動していれば、そのウィンドウで開きます。
- ブラウザ版はファイルをダウンロードして保存します。

### コードエディタ（プログラマーモード）

- 編集中のページのコードを表示します。表示形式は React (TSX) と Vue (SFC) から選べます。
- キャンバスを操作すると、コードがすぐに書き換わります。
- コードを編集すると、入力が止まってから 0.3 秒後に解析し、キャンバスへ反映します。
- 構文エラーや不正な値は、エディタ上の波線と下部の一覧で表示します。エラーがある間はキャンバスに反映しません。
- エラーがある間にキャンバスを操作しても、書きかけのコードは上書きしません。エラーを直すと、コードでの変更とキャンバスでの変更を合わせて反映します（同じプロパティを両方で変えた場合はコードを優先）。不要なら「コードの編集を破棄」でキャンバスの内容に戻せます。書きかけのコードは、ページや形式を切り替えても残ります。
- キャンバスで選択した要素の行を強調表示します。

各要素は `<Box>` で表します。スタイルは、要素タイプごとの既定値と違うものだけを書きます。

```tsx
<Box id="e2" type="button" x={80} y={280} w={140} h={44} to="page-2"
  anim={{ type: 'zoomIn', duration: 0.5, delay: 0.7, iter: '1', easing: 'ease', direction: 'normal', trigger: 'onLoad' }}>
  はじめる
</Box>
```

- 値には、文字列・数値・真偽値・オブジェクトのリテラルだけを使えます。変数や式は使えません。
- 中身のテキストが要素の `text` になります。ラジオボタンとセレクトボックスでは、カンマ区切りの選択肢になります。
- `to` はリンク先のページ ID（`page-1`, `page-2`, …）です。存在しないページはエラーになります。
- `href` は外部のリンク先（`https://`・`http://`・`mailto:`・`tel:`）、`newTab` を付けると新しいタブで開きます。`to` と `href` は同時に使えません。
- `href="#e5"` はページ内の要素 `e5` の位置へ、`href="#top"` はページの先頭へスクロールします。
- `tag` はテキスト・見出しの HTML タグ（`h1`〜`h6`・`p`・`div`）、`alt` は画像の代替テキストです。
- `anim.trigger` はアニメーションのきっかけです：`onLoad`（ページ読込時）・`onView`（スクロールで表示されたとき）・`onClick`（クリック時）・`onHover`（ホバー時）。
- `hover` はマウスを乗せたときの見た目（`{ bg?, color?, shadow?, scale?, y?, underline? }`。`scale` は 0.5〜2、`y` は -100〜100 px）です。
- フォーム：`name` は送信するときの項目名、`inputType` は入力欄の種類（`text`・`email`・`tel`・`number`）、`required` は必須、ボタンの `submit` はフォームの送信です。送信先は `<Page form="https://...">` に書きます。
- メニュー（`type="nav"`）のテキストは、1行が1項目で `ラベル | リンク先`（ページ ID・`#要素のID`・URL）です。
- お知らせ一覧（`type="news"`）のテキストは、1行が1件で `日付 | タイトル` または `日付 | タイトル | リンク先` です。
- メニュー・お知らせ一覧の `hover` は項目ごとの見た目（`color` と `underline`）です。
- `<Page id="page-1">` はページの ID で、メニューで表示中のページの項目に印を付けるのに使います。
- `sp` はスマホで表示するときの位置・サイズ（`{ x, y, w, h, fontSize?, hidden? }`）です。書いていない要素は自動で並べます。
- 色にはテーマの色を `var(--c1)` のように書けます。
- 要素は `<Page>` の中に置きます。`<Page>` の `w`・`h` はページの幅と高さ、`sp` はスマホで表示するときの幅と高さです（ページの大きさはエディタが決めるので、コードで書き換えても反映しません）。
- `group` はグループの ID（`g1` など）、`rotate` は回転角度（度、-360〜360）です。
- `src` は画像の URL です。プロジェクトに埋め込んだ画像は `assets/img-1.png` のように書き、ほかに `http(s)://` の URL を使えます。
- 表のように複数行のテキストは、React では `{'項目,内容\nA,1'}`、Vue では `:text="'項目,内容\nA,1'"` と書きます。
- 値の範囲：`x`・`y` は 0 以上、`w` は 20 以上、`h` は 10 以上、`opacity` は 0〜1、`anim.duration` は 0.1〜10 秒、`anim.delay` は 0〜10 秒、`anim.iter` は 1 以上の整数か `'infinite'`。スタイルの値に `< > { } ; \` は使えません。
- Vue では、数値とオブジェクトを `:x="80"` のようにバインドし、プロパティ名はケバブケース（`font-size`）で書きます。

## 書き出し

「ファイル ▸ 書き出し」から書き出します。

| 書き出し | 出力 |
|---|---|
| Web サイト（公開用） | `site.zip`。`index.html`（最初のページ）とページごとの HTML（`about.html` など）・`style.css`・`script.js`（必要なときだけ）・`assets/`（画像）・`robots.txt`・`sitemap.xml`（公開する URL を設定したとき）・`404.html`（見つからないときのページを設定したとき）。そのまま Web サーバーに置いて公開できます |
| HTML（1ファイル） | `craft-export.html`。全ページを1ファイルに入れた、外部 JS 不要のスタンドアロン HTML（画像も埋め込み）。確認用 |
| React + TypeScript / Vue + TypeScript | `craft-export-react.zip` / `craft-export-vue.zip`。Vite + TS のプロジェクト一式（`npm install && npm run dev` で動く）。画像は `public/assets/` に入ります |

- Web サイト（公開用）は、ページへのリンクが普通の `<a href="about.html">` です。各ページの `<title>`・`description`・OGP（`og:title`・`og:description`・`og:url`・`og:image`）・`canonical`・ファビコン・`lang` を書き出します。
- フォームは `<form action="送信先" method="POST">` と、`form` 属性でつないだ入力欄・送信ボタンとして書き出します。マウスを乗せたときの見た目は `:hover` の CSS、メニューの ☰ ボタンは小さなスクリプトで開閉します。固定するヘッダーは `position: sticky` の `<div class="sticky">`（React / Vue では `<StickyHeader>`）で囲みます。
- HTML（1ファイル）と React / Vue は、URL のハッシュ（`#/page-2`）で表示するページを切り替えます。ブラウザの「戻る」も使えます。追加のライブラリ（ルーター）は使いません。ページを切り替えるとタイトルも変わります。
- スマホ用のレイアウトは、HTML では `@media (max-width: 767px)` の CSS、React / Vue では各 `<Box>` の `sp` として書き出します（自動で並べた分も含めて、全要素に書き出します）。
- ページの中身は幅 1440px で中央に置き、幅いっぱいの帯は画面の端まで伸ばします。ブラウザの幅が 1440px より狭いときは、中身を CSS の `zoom` で縮めます（HTML では `<head>` の小さなスクリプトが倍率 `--s` を計算し、React / Vue では `<Page>` が計算します）。帯は HTML では `band` クラス、React / Vue では `<Box>` が判定します。
- スクロールで表示されたときのアニメーションは、画面に入るまで最初の状態で止めておき、`IntersectionObserver` で画面に入ったら再生します。「ページの先頭へ」ボタンは、HTML では `.to-top`、React / Vue では `<BackToTop>` です。
- HTML 書き出しは、使っているアニメーションの `@keyframes` だけを出力します。各要素は全ページを通して `el-1`〜`el-N` の `position:absolute` で配置し、使っているフォントだけを Google Fonts から読み込みます。PC でもスマホでも非表示の要素は出力しません。
- ソースコードは `src/pages/Page1.tsx`（Vue は `.vue`）のようにページごとのファイルになり、`src/App` がハッシュを見てページを切り替えます。`src/runtime/`（`<Page>`・`<Box>` コンポーネント・既定値・スタイル・キーフレーム・画面遷移・スマホ表示）がそのまま `src/vpe/` として入ります。エディタのキャンバスも同じ `<Box>` で描画しているので、書き出し後と見た目が一致します。
