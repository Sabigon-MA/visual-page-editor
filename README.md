# PageEdit — ビジュアルWebエディタ

コードを書かずに Web ページをビジュアルで組み立てられる、ブラウザ上で動くページエディタです。PowerPoint のような感覚で要素をドラッグ＆ドロップで配置し、アニメーションを設定して、HTML として書き出せます。

インストール・サーバーは不要です。`index.html` をモダンブラウザ（Chrome / Firefox / Edge / Safari）で開くだけで使えます。HTML / CSS / JavaScript はすべて `index.html` 1ファイルに入っています。編集内容は保存されず、ページを再読み込みすると初期状態に戻ります。

## 主な機能

- 要素の追加（左サイドバー／上部「＋ 要素を追加」／キャンバスの右クリック）
- ドラッグで移動、8方向ハンドルでリサイズ、ダブルクリックでテキストを直接編集
- プロパティ：X / Y / 幅 / 高さ、テキスト、文字色、揃え、フォント、サイズ、太字、斜体
- スタイル：塗り色（透明可）、ボーダー（色・幅・線種）、角丸、透明度、影
- アニメーション：17種類、時間・遅延・繰り返し・イージング・方向・トリガー（読込時／クリック時／ホバー時）
- タイムライン表示、全アニメーションの再生
- レイヤーパネル：ドラッグで並び替え、表示／非表示、ロック
- 前面／背面／最前面／最背面、複製、削除、全削除
- 右クリックメニュー
- 編集／プレビューモードの切り替え（上部トグル）
- 元に戻す／やり直す
- HTML 書き出し（`craft-export.html`）

## 要素タイプ

テキスト、見出し、四角形、円、区切り線、ボタン、入力欄、テキストエリア、チェックボックス、ラジオボタン、セレクトボックス、スライダー、画像プレースホルダー、カード。

ラジオボタンとセレクトボックスの選択肢は、カンマ区切りで入力します。

## キーボードショートカット

| キー | 動作 |
|---|---|
| Ctrl/⌘ + Z | 元に戻す |
| Ctrl/⌘ + Y / Ctrl/⌘ + Shift + Z | やり直す |
| Ctrl/⌘ + D | 選択要素を複製 |
| Ctrl/⌘ + B | 太字切替 |
| Ctrl/⌘ + I | 斜体切替 |
| Delete / Backspace | 選択要素を削除 |
| ↑↓←→ | 1px 移動（Shift で 10px） |
| Escape | 選択解除 |

## 書き出し HTML

- Google Fonts（DM Sans / Playfair Display / DM Mono）を読み込みます。
- 使っているアニメーションの `@keyframes` だけを出力します。
- 各要素はクラス `el-1`〜`el-N` の `position:absolute` で配置します。中の `.in` 要素に見た目とアニメーションを指定します。
- フォーム要素は、実際に操作できる HTML 要素として出力します。
- 非表示の要素は出力しません。
- クリック時のアニメーションは、クリックするたびに再生されるよう短いインライン JS を含めます。スライダーのラベル更新にも `oninput` を使います。
- キャンバスは幅 800px 固定です。レスポンシブには対応していません。
